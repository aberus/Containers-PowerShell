# Stop-Container

## SYNOPSIS

Stops a running container.

## SYNTAX

### Default (Default)

```
Stop-Container [-ContainerIdOrName] <string[]> [-Force] [-PassThru] [-HostAddress <string>]
 [-Context <string>] [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### ContainerObject

```
Stop-Container [-Container] <ContainerListResponse[]> [-Force] [-PassThru] [-HostAddress <string>]
 [-Context <string>] [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Stops a running container.

## EXAMPLES

### Example 1

Stops the container named "myContainer".

```powershell
PS C:\> Stop-Container -ContainerIdOrName myContainer
```
