# Get-Container

## SYNOPSIS

Returns a list of containers.

## SYNTAX

### Default (Default)

```
Get-Container [[-ContainerIdOrName] <string[]>] [-All] [-HostAddress <string>] [-Context <string>]
 [-CertificateLocation <string>] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Returns a list of containers.

## EXAMPLES

### Example 1

Retrieves a list of containers.

```powershell
PS C:\> Get-Container
```
