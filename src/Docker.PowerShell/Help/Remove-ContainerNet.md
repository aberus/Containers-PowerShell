# Remove-ContainerNet

## SYNOPSIS

Removes a network endpoint.

## SYNTAX

### Default (Default)

```
Remove-ContainerNet [-Id] <string[]> [-Force] [-HostAddress <string>] [-Context <string>]
 [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### NetworkObject

```
Remove-ContainerNet [-Network] <NetworkResponse[]> [-Force] [-HostAddress <string>]
 [-Context <string>] [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Removes a network endpoint.

## EXAMPLES

### Example 1

Removes the network endpoint named "Virtual Switch"

```powershell
PS C:\> Remove-ContainerNet -Id "Virtual Switch"
```
