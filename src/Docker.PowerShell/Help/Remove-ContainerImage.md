# Remove-ContainerImage

## SYNOPSIS

Removes a container image.

## SYNTAX

### Default (Default)

```
Remove-ContainerImage [-ImageIdOrName] <string[]> [-Force] [-HostAddress <string>]
 [-Context <string>] [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### ImageObject

```
Remove-ContainerImage [-Image] <ImagesListResponse[]> [-Force] [-HostAddress <string>]
 [-Context <string>] [-CertificateLocation <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Removes a container image.

## EXAMPLES

### Example 1

Removes the container with id "124dfe"

```powershell
PS C:\> Remove-ContainerImage -ImageIdOrName 124dfe
```
