# Submit-ContainerImage

## SYNOPSIS

Pushes an image to its registry.

## SYNTAX

### Default (Default)

```
Submit-ContainerImage [-ImageIdOrName] <string> [-PassThru] [-Force] [-RegistryAuth <string>]
 [-Session <Session>] [-SessionName <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### ImageObject

```
Submit-ContainerImage [-Image] <ImageInfo> [-PassThru] [-Force] [-RegistryAuth <string>]
 [-Session <Session>] [-SessionName <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has the following aliases: "Push-ContainerImage".

## DESCRIPTION

Pushes an image to the registry its name points at, reporting progress as it uploads. Authentication comes from -RegistryAuth, or from the token stored earlier by Connect-ContainerRegistry.

## EXAMPLES

### Example 1

Pushes an image to its registry without prompting

```powershell
PS C:\> Submit-WslcContainerImage ghcr.io/myorg/myapp:v1 -Force
```
