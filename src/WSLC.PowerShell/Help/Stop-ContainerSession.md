# Stop-ContainerSession

## SYNOPSIS

Terminates a WSLC session and the virtual machine backing it.

## SYNTAX

### Default (Default)

```
Stop-ContainerSession [[-Name] <string[]>] [-Session <Session>] [-SessionName <string>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Terminates a WSLC session, shutting down the virtual machine that backs it, and stops tracking it in this process. It never creates a session just to tear it down.

## EXAMPLES

### Example 1

Terminates the default session

```powershell
PS C:\> Stop-WslcContainerSession
```
